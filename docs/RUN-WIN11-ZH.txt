TaskbarOrder 0.1.1（Windows 11 x64 实验版）
==============================================

文件说明
--------
TaskbarOrder.exe              双击运行的控制程序
TaskbarOrderHook-0.1.1.dll    调序引擎，必须与 EXE 放在同一目录

首次使用
--------
1. 将 ZIP 完整解压到普通文件夹，不要只从压缩包里双击 EXE。
2. 双击 TaskbarOrder.exe。
3. 程序会自动检测环境；确认报告里是 Windows 11、x64。
4. 点击“准备符号”。首次需要访问 Microsoft 符号服务器。
5. 完成后点击“启用调序”。
6. 鼠标悬停在任务栏中的 IDEA 图标上，在弹出的两个窗口预览卡片之间按住左键拖动。

停用与退出
----------
点击“停用调序”，或直接退出 TaskbarOrder。最小化后程序位于系统托盘。

当前验证状态
------------
本包已经交叉编译为 PE32+ x86-64，并检查了系统 DLL 依赖。
在 Windows 11 Enterprise 25H2、Build 26200.9445 上，0.1.0 的符号准备成功，
启用时触发任务项布局保护检查。0.1.1 会把结构化布局摘要写入 engine.log；
不记录 DLL 原始字节，也不会在检查失败后安装调序钩子。
请点击“打开日志”，找到 engine.log 中以 GetNumItems layout profile: 开头的
一行，以及其后的初始化失败信息。经公司规定允许后，提供这两行即可。
