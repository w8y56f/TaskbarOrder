TaskbarOrder 0.1.3（Windows 11 x64 实验版）
==============================================

文件说明
--------
TaskbarOrder.exe              双击运行的控制程序
TaskbarOrderHook-0.1.3.dll    调序引擎，必须与 EXE 放在同一目录

首次使用
--------
1. 将 ZIP 完整解压到普通文件夹，不要只从压缩包里双击 EXE。
2. 双击 TaskbarOrder.exe。
3. 程序会自动检测环境；确认报告里是 Windows 11、x64。
4. 点击“准备符号”。首次需要访问 Microsoft 符号服务器。
5. 完成后点击“启用调序”。
6. 鼠标悬停在任务栏中的 IDEA 图标上，在弹出的两个窗口预览卡片之间按住左键拖动。

停用与退出
----------
点击“停用调序”，或直接退出 TaskbarOrder。最小化后程序位于系统托盘。

当前验证状态
------------
本包已在 Windows x64 环境编译并通过自动测试。
在 Windows 11 Enterprise 25H2、Build 26200.9445 上，0.1.0 的符号准备成功，
启用时触发任务项布局保护检查。0.1.2 的结构化日志显示了带判空分支的
GetNumItems 函数形式。0.1.3 对这条精确指令序列增加了受限匹配；仍需在
VDI 上验证启用和实际拖动。若启用失败，点击“打开日志”，提供 engine.log
和 controller.log 中本次运行的新记录。经公司规定允许后再提供日志。
