TaskbarOrder 0.9.0（Windows 11 x64 实验版）
==============================================

文件说明
--------
TaskbarOrder.exe              双击运行的控制程序
TaskbarOrderHook-0.9.0.dll    调序引擎，必须与 EXE 放在同一目录

首次使用
--------
1. 将 ZIP 完整解压到普通文件夹，不要只从压缩包里双击 EXE。
2. 双击 TaskbarOrder.exe。
3. 程序会自动检测环境；确认报告里是 Windows 11、x64。
4. 点击“准备符号”。首次需要访问 Microsoft 符号服务器。
5. 完成后点击“启用调序”。
6. 鼠标悬停在任务栏中的 IDEA 图标上，在弹出的两个窗口预览卡片之间按住左键拖动。

停用与退出
----------
点击“停用调序”可停止调序。最小化或点击 × 后程序收进通知区域并继续运行。
双击通知区域图标可恢复窗口；彻底退出请使用“设置 → 退出”或托盘右键菜单。
勾选“设置 → 登录 Windows 时启动”后，登录时自动从通知区域启动；匹配缓存存在时尝试自动启用。
移动解压目录后，请从新目录重新勾选此项。

日常启动与本次升级
------------------
符号缓存匹配时，启动后等自动检测结束，直接点“启用调序”。
Windows 任务栏组件更新、缓存被清除，或程序增加了符号项时，需重新准备符号。
0.9.0 增加了符号项：从 0.1.3 或更早版本升级时，请再点一次“准备符号”，会复用已有 PDB。
先退出旧版，重启 Windows 资源管理器或注销再登录，再运行新版本。
启用后先移开鼠标关闭预览，再悬停打开预览并拖动。

当前验证状态
------------
0.1.3 在目标 VDI 上已能启用，但用户反馈左键拖动无效。
0.9.0 改用实际缩略图集合和 ItemsRepeater 的实时索引，补充拖动阶段日志。
源代码修改尚待 Windows 构建及 VDI 验证，不代表问题已确认修复。
若仍无效，停用后再启用、打开预览、拖动一次，查看 engine.log 本次的新记录。
日志仅记录阶段和匹配情况，不记录窗口标题、文档内容或 DLL 原始指令。

“设置 → 关于”显示软件名称、版本、构建提交 ID 和 Powered by Stone Wang。
